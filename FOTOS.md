# Onde colocar cada foto

O site acha a foto pelo nome do arquivo (sem a extensão). Aceita .jpg, .jpeg, .png e .webp. Se a foto existir, ela aparece sozinha no lugar do espaço tracejado. Depois, rode npm run fotos para padronizar o tamanho.

## Geral (src/assets)
- balcao.jpg: foto de destaque do topo, em pé (1200 x 1600 px)
- faixa.jpg: foto larga do interior ou estoque (1600 x 700 px). Sem ela, a faixa não aparece
- logo.png: logo da loja
